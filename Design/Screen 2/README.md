# ZGRNK HH Agent — дизайн-мокап (вариант 2)

Экспорт из Stitch, только фронтенд-мокап с фейковыми данными (localStorage). Не подключён к реальному боту.
Поля формы (`AgentSettings` в `src/types.ts`) практически совпадают с `config.py` основного проекта — этот вариант выбран как основа для реальной интеграции (см. `gui_app.py` в корне репозитория).

## Запуск локально
```bash
npm install
npm run dev
```
