# HH.ru AI Agent

Форк [fikstt2/hh-ai-agent](https://github.com/fikstt2/hh-ai-agent).

Агент ищет вакансии на HH.ru, отсеивает мусор, пишет уникальное сопроводительное письмо через LLM (DeepSeek в облаке или локальная Ollama) и откликается сам. Управление и уведомления через Telegram-бота.

## Чем этот форк отличается от оригинала

Оригинал был CLI-скриптом: одно резюме, конфиг правится руками в `.env`, запуск через `python main.py`, для работы нужны Python, Node и ручная установка Playwright/Chromium.

Здесь добавлено:
- **GUI** на React (вкладки "Настройки" и "Логи") поверх pywebview, форма сама читает и пишет `.env`.
- **Один `.exe`**, без Python и Node.js на машине пользователя. Бот работает прямо в процессе GUI-приложения, а не отдельным скриптом. Chromium докачивается сам при первом запуске.
- **Несколько резюме-профилей**: можно завести профиль под каждую специализацию (например бэкенд и фронтенд), у каждого свои поисковые запросы, текст для писем и резюме на hh.ru, бот ищет и откликается по каждому отдельно.
- **Импорт резюме**: текст можно затянуть из PDF (парсится автоматически) или прямо с hh.ru кнопкой "Импортировать" (текст со страницы резюме подтягивается через уже авторизованную сессию бота).
- **Импорт сессии из другого браузера**: если бот не может сам пройти вход (не приходит код и т.п.), сессию можно перенести из уже залогиненного браузера через `import_cookies.py`, без повторного ввода SMS-кода.
- Ряд багфиксов вокруг стабильности: живые логи в GUI больше не теряются при переключении вкладок, окно установки Chromium больше не падает с 404, сбой при старте бота (например невалидный токен) теперь виден в логах, а не убивает поток молча.

## Возможности

- **Парсинг через Playwright**: сохраняет сессию авторизации, пробрасывает капчу в подключенного Telegram-бота, если она всплыла.
- **Двойная фильтрация**: хард-фильтр по стоп-словам плюс анализ вакансии через LLM (отсекает нерелевантное вроде "продажников" и "риелторов", даже если оно попало в выдачу IT-поиска).
- **Сопроводительные письма под резюме**: LLM читает текст резюме и вакансию и пишет письмо под конкретный отклик.
- **Telegram**: уведомления об откликах с текстом письма, пересылка ответов HR прямо в мессенджер.
- **Работает без присмотра**: бесконечный цикл с паузой (по умолчанию 30 минут).
- **Дедупликация**: история откликов в SQLite, вакансия, на которую уже откликались или которую уже разобрал ИИ, повторно не обрабатывается, даже после перезапуска.

## Быстрый старт (просто .exe)

1. Скачайте `hh-agent.exe` со страницы [Releases](https://github.com/zzeygarnik/hh-ai-agent/releases).
2. Запустите. В окне "Настройки" заполните токен Telegram-бота, LLM-провайдера, профиль резюме и поисковые запросы, нажмите "Сохранить".
3. На вкладке "Логи" нажмите "Старт".
   - При первом запуске бота докачается Chromium (короткое окно прогресса, закроется само).
   - Затем откроется видимое окно браузера, нужно один раз вручную войти в аккаунт HH.ru (код из SMS или почты). Сессия сохранится в `state.json`, дальше бот работает в фоне без видимого окна.
   - Если вход через видимое окно не проходит (код не приходит и т.п.), можно перенести сессию из другого браузера, где вы уже залогинены, см. раздел ниже.
4. Логи видно прямо в приложении и в файле `agent.log` рядом с `.exe`.

## Импорт сессии из другого браузера

Разово, когда обычный вход в приложении не работает:

1. В браузере, где вы уже залогинены на hh.ru, поставьте расширение вроде Cookie-Editor.
2. На странице hh.ru экспортируйте куки в JSON.
3. Запустите `python import_cookies.py путь/к/файлу.json` из папки проекта (нужен Python).

Скрипт смержит куки с доменом hh.ru в `state.json`, бот при следующем запуске подхватит сессию без окна логина.

## Запуск из исходников (для разработки)

### Требования
- Python 3.9+
- Node.js 18+, только для сборки/разработки GUI (`frontend/`), самому боту (`main.py`) Node не нужен.
- API-ключ [DeepSeek](https://platform.deepseek.com/) (провайдер по умолчанию, платный по балансу) либо установленный [Ollama](https://ollama.com/) с загруженной моделью для локальной работы бесплатно.

### 1. Зависимости
```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. Настройка окружения
Скопируйте `.env.example` в `.env`. Проще всего заполнить его через GUI, форма сама читает и пишет файл. Свой Telegram ID можно узнать через бота @userinfobot.

### 3. Запуск GUI
```bash
pip install -r requirements-dev.txt
npm --prefix frontend install
npm --prefix frontend run build
python gui_app.py
```
Бот запускается и останавливается кнопками на вкладке "Логи", отдельно `main.py` запускать не нужно.

Либо соберите тот же `.exe`, что в разделе "Быстрый старт":
```powershell
powershell -File build_exe.ps1
```
Результат: `dist\hh-agent.exe`, самодостаточный. Node.js нужен только на машине, где собираете.

### 4. Настройка поиска под себя
Резюме-профили (`RESUME_PROFILES` в `.env`, JSON-массив, проще через GUI): один или несколько, бот ищет и откликается по каждому отдельно. У каждого профиля:
- точное название резюме на hh.ru (символ в символ, как в личном кабинете, бот выбирает по нему резюме при отклике, само резюме бот не создаёт);
- поисковые запросы, например "Python backend", "FastAPI";
- текст резюме для LLM, на его основе пишутся письма. Опишите стек, проекты, пожелания подробно или прикрепите PDF, текст извлечётся сам.

Регионы поиска: флаги `SEARCH_REGION_MOSCOW` / `SEARCH_REGION_SPB` / `SEARCH_REGION_REMOTE` в `.env` (по умолчанию СПб и удалёнка по РФ, общие для всех профилей), в GUI это чекбоксы.

### 5. Запуск без GUI (CLI)
```bash
python main.py
```
При первом запуске откроется окно браузера для входа, дальше режим headless. Остановка Ctrl+C.
