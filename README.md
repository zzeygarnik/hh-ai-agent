# HH.ru AI Agent (Auto-Responder) 🤖💼

> Форк [fikstt2/hh-ai-agent](https://github.com/fikstt2/hh-ai-agent).

Полностью автономный ИИ-агент для автоматического поиска вакансий на HH.ru, фильтрации мусора и рассылки уникальных сопроводительных писем с помощью LLM (облачный DeepSeek или локальная Ollama). Управляется и отправляет отчеты через Telegram-бота.

## Фичи
- **Умный парсинг**: обходит Cloudflare и блокировки HH.ru за счет Playwright (сохраняет сессию авторизации, пробрасывает капчу в тг).
- **Двойная фильтрация**: хард-фильтр по стоп-словам + интеллектуальный анализ вакансии через LLM (отсекает нерелевантные вакансии вроде "продажников" и "риелторов", даже если они всплыли в поиске по IT).
- **Кастомные сопроводительные письма**: нейросеть читает ваше резюме и текст вакансии, выдавая идеальное персонализированное письмо для отклика.
- **Интеграция с Telegram**: бот присылает уведомления об успешных откликах вместе со сгенерированным письмом, а также пересылает вам ответы от HR напрямую в мессенджер.
- **Работает 24/7**: бесконечный цикл с задержками (по умолчанию 30 минут) позволяет боту работать на вас круглосуточно.
- **GUI-настройки**: `gui_app.py` (или собранный `.exe`) — форма для токенов/профиля/поиска вместо ручного редактирования `.env`, плюс кнопки запуска/остановки бота с логом в реальном времени.

## Требования
- Python 3.9+
- Либо API-ключ [DeepSeek](https://platform.deepseek.com/) (провайдер по умолчанию, платно по балансу), либо установленный [Ollama](https://ollama.com/) с загруженной моделью (`llama3` и т.п.) для локальной работы бесплатно.

## Настройка

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. Настройка окружения
Скопируйте `.env.example` в `.env` и заполните значения — токены, выбор LLM-провайдера (`LLM_PROVIDER=deepseek` или `ollama`), данные профиля (`MY_NAME`, `MY_GITHUB`, `MY_PET_PROJECT`).

Проще всего это сделать через `python gui_app.py` — форма читает и пишет `.env` сама, ничего руками редактировать не нужно.

*(Свой Telegram ID можно узнать через бота @userinfobot).*

### 3. Настройка поиска под себя
В `config.py` (или через GUI):
- `SEARCH_QUERIES` — список запросов (например, "Python backend").
- `SEARCH_AREAS` — регионы поиска (по умолчанию Санкт-Петербург + удалённка по РФ, меняются параметром `area` в URL hh.ru).
- `TARGET_RESUME_NAME` — точное название вашего резюме на HH (чтобы бот выбирал правильное из списка).
- `MY_RESUME_SUMMARY` — подробное текстовое саммари ваших навыков. **Это критически важно**, так как на основе этого текста ИИ будет писать сопроводительные письма. Опишите свой стек, проекты и пожелания максимально подробно.

### 4. Первый запуск (Авторизация)
При самом первом запуске скрипт откроет видимое окно браузера:
```bash
python main.py
```
Вам нужно **вручную войти в свой аккаунт HH.ru** (ввести код из SMS/почты). Как только вы войдете, скрипт сохранит куки в файл `state.json`. После этого можете закрыть скрипт (Ctrl+C).

### 5. Боевой запуск
Запускайте скрипт заново (или кнопкой "Запустить бота" в `gui_app.py`):
```bash
python main.py
```
Теперь браузер запустится в скрытом режиме (headless) и начнет автоматически собирать вакансии. Напишите боту в Telegram `/start`, чтобы он проснулся и начал слать вам отчеты. Логи пишутся в `agent.log`.
