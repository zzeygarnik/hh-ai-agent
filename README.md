# HH.ru AI Agent (Auto-Responder) 🤖💼

> Форк [fikstt2/hh-ai-agent](https://github.com/fikstt2/hh-ai-agent).

Полностью автономный ИИ-агент для автоматического поиска вакансий на HH.ru, фильтрации мусора и рассылки уникальных сопроводительных писем с помощью LLM (облачный DeepSeek или локальная Ollama). Управляется и отправляет отчеты через Telegram-бота.

## Фичи
- **Умный парсинг**: обходит Cloudflare и блокировки HH.ru за счет Playwright (сохраняет сессию авторизации, пробрасывает капчу в тг).
- **Двойная фильтрация**: хард-фильтр по стоп-словам + интеллектуальный анализ вакансии через LLM (отсекает нерелевантные вакансии вроде "продажников" и "риелторов", даже если они всплыли в поиске по IT).
- **Кастомные сопроводительные письма**: нейросеть читает ваше резюме и текст вакансии, выдавая идеальное персонализированное письмо для отклика.
- **Интеграция с Telegram**: бот присылает уведомления об успешных откликах вместе со сгенерированным письмом, а также пересылает вам ответы от HR напрямую в мессенджер.
- **Работает 24/7**: бесконечный цикл с задержками (по умолчанию 30 минут) позволяет боту работать на вас круглосуточно.
- **Один `.exe`**: скачал — запустил. Бот (Playwright, aiogram, вся логика) работает прямо внутри GUI-приложения, никакой Python/Node.js на машине конечного пользователя не нужен. Chromium для Playwright докачивается сам при первом запуске бота (показывается маленькое окно прогресса), браузер и pip-пакеты руками ставить не надо.

## Быстрый старт (просто .exe)
1. Скачайте `hh-agent.exe` (Releases, либо соберите сами — см. ниже).
2. Запустите. Откроется окно "ZGRNK HH Agent" — заполните вкладку "Настройки" (токен Telegram-бота, LLM-провайдер, профиль, поисковые запросы) и нажмите "Сохранить".
3. Перейдите на "Логи и запуск" → "Запустить бота".
   - При первом запуске бота докачается Chromium (отдельное окошко с прогрессом, закроется само).
   - Затем откроется видимое окно браузера — нужно **один раз вручную войти в свой аккаунт HH.ru** (код из SMS/почты). Сессия сохранится в `state.json`, дальше бот работает в фоне без видимого браузера.
4. Всё. Логи видно прямо в приложении и в файле `agent.log` рядом с `.exe`.

## Запуск из исходников (для разработки)

### Требования
- Python 3.9+
- Node.js 18+ — только для сборки/разработки GUI (`frontend/`); самому боту (`main.py`) Node не нужен.
- Либо API-ключ [DeepSeek](https://platform.deepseek.com/) (провайдер по умолчанию, платно по балансу), либо установленный [Ollama](https://ollama.com/) с загруженной моделью (`llama3` и т.п.) для локальной работы бесплатно.

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. Настройка окружения
Скопируйте `.env.example` в `.env` и заполните значения — токены, выбор LLM-провайдера (`LLM_PROVIDER=deepseek` или `ollama`), данные профиля (`MY_NAME`, `MY_GITHUB`).

Проще всего это сделать через GUI (см. ниже) — форма читает и пишет `.env` сама, ничего руками редактировать не нужно.

*(Свой Telegram ID можно узнать через бота @userinfobot).*

### 3. Запуск GUI
```bash
pip install -r requirements-dev.txt
npm --prefix frontend install
npm --prefix frontend run build
python gui_app.py
```
Бот запускается и останавливается прямо из GUI (кнопки на вкладке "Логи и запуск") — отдельно `main.py` руками запускать не нужно.

Либо соберите тот же `.exe`, что и в "Быстром старте":
```powershell
powershell -File build_exe.ps1
```
Результат — `dist\hh-agent.exe`, полностью самодостаточный (Node.js нужен только на машине, где собираете).

### 4. Настройка поиска под себя
В `config.py` (или через GUI):
- `SEARCH_QUERIES` — список запросов (например, "Python backend").
- Регионы поиска — флаги `SEARCH_REGION_MOSCOW` / `SEARCH_REGION_SPB` / `SEARCH_REGION_REMOTE` в `.env` (по умолчанию СПБ + удалённка по РФ), в GUI — чекбоксы.
- `TARGET_RESUME_NAME` — точное название вашего резюме на HH (чтобы бот выбирал правильное из списка).
- `MY_RESUME_SUMMARY` — подробное текстовое саммари ваших навыков. **Это критически важно**, так как на основе этого текста ИИ будет писать сопроводительные письма. Опишите свой стек, проекты и пожелания максимально подробно.

### 5. Запуск без GUI (CLI)
```bash
python main.py
```
При первом запуске откроется видимое окно браузера для входа в HH.ru (см. "Быстрый старт" выше), дальше — headless-режим. Остановка — Ctrl+C.
